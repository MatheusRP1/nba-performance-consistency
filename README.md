# 🏀 NBA Performance Insights
Este projeto explora o desempenho individual de jogadores da NBA utilizando um banco de dados NoSQL para analisar e comparar estatísticas de jogos disputados dentro e fora de casa. Nosso objetivo principal é identificar jogadores com padrões de desempenho mais constantes e aqueles que demonstram maior inconstância dependendo do ambiente de jogo, fornecendo insights valiosos sobre a adaptabilidade e regularidade dos atletas da liga.**NBA Performance Insights** é um sistema robusto e personalizável que analisa e compara o desempenho individual dos atletas da liga em jogos disputados **em casa** e **fora de casa**, oferecendo estatísticas valiosas para tomada de decisão em contextos como fantasy games, apostas esportivas e análises técnicas.

---

## 🚀 Visão Geral

O **NBA Performance Insights** foi desenvolvido principalmente para as franquias, sendo viável também para analistas, fãs e entusiastas do basquete que desejam automatizar a observação de padrões de desempenho e obter informações precisas e contextualizadas.

Em vez de acompanhar manualmente planilhas ou estatísticas dispersas, o sistema oferece uma visão clara da **regularidade e adaptabilidade dos jogadores**, destacando aqueles que mantêm o nível de atuação independente do local do jogo.

---

## ✨ Principais Funcionalidades

📊 **Análise de Desempenho Domicílio x Visitante**
Compare facilmente as médias e variações de desempenho de cada jogador em jogos disputados em casa e fora.

📬 **Notificações por E-mail (Opcional)**
Receba relatórios periódicos com destaques de jogadores em alta ou queda de rendimento.

📈 **Estatísticas Detalhadas dos Jogadores**
Cada análise inclui métricas relevantes como pontos, assistências, rebotes ofensivos, rebotes defensivos, arremessos convertidos, entre outras.

⏱️ **Monitoramento em Tempo Real**
O sistema pode ser integrado a APIs de dados esportivos para atualização contínua das estatísticas (com foco inicial em dados históricos).

---

## 🛠️ Tecnologias Utilizadas

**Python**
Linguagem principal para o backend do sistema, ideal para processamento de dados, análises estatísticas e automação.

**MongoDB**
Banco de dados NoSQL flexível e escalável, utilizado para armazenar as estatísticas dos jogadores, categorizadas por local da partida (casa/fora), além de relatórios de desempenho e análises agregadas.

**APIs de Dados Esportivos** (ex: NBA Stats API ou fontes públicas)
Fontes de dados utilizadas para obter informações sobre partidas, jogadores e estatísticas detalhadas.
